\# 🌱 Central Saúde v1.0.0



A \*\*Central Saúde\*\* é uma plataforma de telemetria pessoal integrando dados fisiológicos, bioimpedância, exames laboratoriais e assistente virtual de saúde.



\---



\## 🚀 Funcionalidades Principais



\* \*\*📊 Dashboard de Telemetria:\*\* Acompanhamento de passos, sono, frequência cardíaca, SpO₂ e níveis de estresse.

\* \*\*⚖️ Composição Corporal \& Bioimpedância:\*\* Cálculo de IMC, massa magra, % de gordura e taxa metabólica basal (TMB).

\* \*\*🍎 Calculadora de TDEE \& Macros:\*\* Gasto energético diário adaptativo com sugestão prática de cardápio via IA.

\* \*\*🩺 Exames Laboratoriais (Sabin/Fleury):\*\* Leitura de PDFs e monitoramento automático de marcadores fora de referência.

\* \*\*📑 Dossiê Médico em PDF (1 página):\*\* Exportação de relatório consolidado para consultas médicas.

\* \*\*🧠 Saúde Mental \& Diário TCC:\*\* Mapeamento de humor, gatilhos emocionais e descompressão.



\---



\## 💻 Como Instalar \& Usar



\### 🪟 Windows

1\. Baixe o pacote \*\*`CentralSaude-v1.0.0-Windows.zip`\*\* na aba \[Releases](../../releases).

2\. Extraia o conteúdo do arquivo `.zip`.

3\. Dê dois cliques no arquivo `instalar\_central.bat` para configurar o ambiente e a IA local.

4\. Para abrir o sistema no dia a dia, dê dois cliques em `iniciar\_central.bat`.



\### 🍎 macOS

1\. Baixe o pacote \*\*`CentralSaude-v1.0.0-macOS.zip`\*\* na aba \[Releases](../../releases).

2\. Extraia o conteúdo do arquivo `.zip`.

3\. Clique duas vezes em `instalar\_central.command`.

4\. Para usar no dia a dia, dê dois cliques em `iniciar\_central.command`.
