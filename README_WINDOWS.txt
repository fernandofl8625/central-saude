===================================================
      CENTRAL SAÚDE v1.0.0 - GUIA WINDOWS
===================================================

1. PRIMEIRO ACESSO (Instalação):
   - Dá dois cliques no arquivo 'instalar_central.bat'.
   - O instalador vai configurar o Python, instalar o motor de IA local (Ollama) e baixar o modelo Llama em segundo plano.

2. USO DIÁRIO:
   - Dá dois cliques no arquivo 'iniciar_central.bat'.
   - O sistema abrirá automaticamente no seu navegador padrão.
